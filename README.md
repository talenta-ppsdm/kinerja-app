# Aplikasi Pengelolaan Kinerja - PPSDM

Aplikasi ini dikembangkan oleh **Tim Manajemen Talenta PPSDM** sebagai alat bantu digital untuk mengelola, memantau, dan mengorganisir pekerjaan.

## 📋 Deskripsi Proyek
Aplikasi ini hadir untuk menjembatani kebutuhan administrasi kepegawaian dengan teknologi informasi. Fokus utama pengembangan adalah untuk memastikan setiap tahapan pengelolaan kinerja pegawai terdokumentasi dengan baik dan dapat dimonitor secara real-time.

## ✨ Fitur Utama
* **Dashboard Monitoring Kinerja:** Visualisasi data untuk memantau progres kerja tim secara menyeluruh.
* **Manajemen SKP:** Fitur khusus untuk mengelola siklus Sasaran Kinerja Pegawai, mulai dari:
    * **Penyusunan SKP:** Input dan pengarsipan target kinerja tahunan.
    * **Evaluasi SKP:** Modul penilaian dan peninjauan capaian kinerja pegawai.

## 🚀 Teknologi yang Digunakan
* **Framework:** Laravel (PHP)
* **Database:** MySQL
* **Frontend:** Bootstrap 
* **Tools:** Git untuk version control
